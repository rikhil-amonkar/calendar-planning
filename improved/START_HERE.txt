================================================================================
🎯 KEY FINDINGS
================================================================================

✅ Python prompting is VASTLY superior to SMT:
   - GPT-5: 95% (Python) vs 10% (SMT)
   - Use Python for all meeting planning tasks

✅ Best Models:
   1. Deepseek-Reasoner-Python: 97% accuracy
   2. GPT-5-Python: 95% accuracy
   3. O3-mini-Python: 82% accuracy

✅ Two Evaluation Methods:
   - LLM Judge: Stricter, catches optimality issues
   - Constraint-Based: More reliable, no hallucinations
   - Use BOTH for comprehensive evaluation

================================================================================
💡 RECOMMENDED WORKFLOW
================================================================================

For a new model:

1. Run inference:
   python code_generation_inference.py --model MODEL_NAME --task meeting --num_samples 100

2. Evaluate with LLM judge:
   python llm_judge_evaluator.py results/OUTPUT.json gpt-5.2

3. Evaluate with constraints:
   python convert_to_structured_output.py results/OUTPUT.json
   python evaluate_structured_outputs.py results/OUTPUT_structured.json meeting_planning_100_constraints.json

4. Compare results:
   python compare_all_evaluations.py
