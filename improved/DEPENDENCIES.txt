# Dependencies and Requirements

## Python Version
- Python 3.8 or higher

## Required Python Packages

### Core Dependencies
- openai>=1.0.0         # OpenAI API client
- python-dotenv>=0.19.0 # Environment variable management
- pandas>=1.3.0         # Data manipulation and CSV export

### For Local Models (Optional)
- torch>=2.0.0          # PyTorch for model inference
- transformers>=4.30.0  # HuggingFace transformers
- accelerate>=0.20.0    # Model acceleration utilities

### For Constraint Evaluation
- z3-solver>=4.8.0      # Z3 SMT solver (if using SMT strategy)

## Installation

### Basic Setup (OpenAI/Deepseek only)
```bash
pip install openai python-dotenv pandas
```

### Full Setup (including local models)
```bash
pip install openai python-dotenv pandas torch transformers accelerate
```

### Using Virtual Environment (Recommended)
```bash
python -m venv venv
source venv/bin/activate  # On Linux/Mac
# or
venv\Scripts\activate  # On Windows

pip install openai python-dotenv pandas
```

## API Keys Required

### OpenAI API Key (Required)
- Sign up at: https://platform.openai.com/
- Add to .env file: OPENAI_API_KEY=sk-...

### Deepseek API Key (Optional)
- Sign up at: https://platform.deepseek.com/
- Add to .env file: DEEPSEEK_API_KEY=sk-...

## Hardware Requirements

### For API-based models (GPT, Deepseek)
- Any modern CPU
- 4GB+ RAM
- Internet connection

### For local models (Qwen)
- NVIDIA GPU with 24GB+ VRAM (for 32B models)
- 32GB+ system RAM
- 100GB+ disk space for model weights

## Dataset

The meeting planning dataset is included:
- meeting_planning_100_constraints.json (ground truth constraints)

Original dataset source: NaturalPlan benchmark
