     How to compute these stays from the base_city array?

        The base_city array tells us the city we wake up in each day.

        We know that the base city changes only on travel days.

        We can define:

          stays = []
          current_city = base_city[1]
          start_day = 1
          for day in range(2, n_days+1):
             if base_city[day] != current_city:
                 stays.append( (start_day, day-1, current_city) )
                 current_city = base_city[day]
                 start_day = day-1   # because day-1 is the last day of the previous stay, and also the first day of the new stay? But note: on day-1 we traveled to current_city, so we are in the new city on day-1 (as travel destination) and we wake up in the new city on day.
                 # Actually, the base_city for day is the new city, which means we woke up in the new city on day. So the new stay should start on day-1? Because the travel happened on day-1, so we are in the new city on day-1.

          But wait: the base_city for day is the city we wake up in on that day. So if we travel on day-1, then we wake up on day in the new city. So the new city's stay starts on day (the day we wake up there). However, we were also in the new city on day-1 (travel day). So to account for the travel day, we should start the new stay on day-1.

          However, the previous stay ended on day-1 because we left that city on day-1. So we have:

            stay1: day1 to day1 (if we travel on day1) or day1 to day2 if we travel on day2?

          Let's take an example:

            base_city[1] = PA
            base_city[2] = PA   (no travel on day1)
            base_city[3] = VI   (travel on day2 to VI)

            Then we are in PA on day1 and day2 (base) and on day2 we travel to VI, so we are in VI on day2.
            We wake up in VI on day3.

            So the stay in PA should be from day1 to day2 (because we are in PA on day1 and day2).
            The stay in VI should be from day2 to day3 (because we are in VI on day2 and day3).

          So the stays are:

            PA: day1-2
            VI: day2-3

          Note: day2 is included in both.

          How to compute this algorithmically:

            We'll iterate from day1 to day16, and whenever base_city[i] != base_city[i+1] (for i from 1 to 15), then we end the current stay at day i, and start a new stay at day i (for the new city) and then continue.

            But note: the new city's stay starts at day i because we are in that city on day i (as travel destination) and then we wake up there on day i+1.

          So we can do:

            stays = []
            current_city = base_city[1]
            start = 1
            for i in range(1, n_days):
                if base_city[i+1] != current_city:
                    stays.append( (start, i, current_city) )
                    current_city = base_city[i+1]
                    start = i
            stays.append( (start, n_days, current_city) )

          Then, for the example above:

            i=1: base_city[2] = PA, which equals current_city (PA) -> no change.
            i=2: base_city[3] = VI, which is not PA -> we end the PA stay at day2, and start a VI stay at day2.
            Then we add the last stay: (2, 3, VI)

          So we get:
            [ (1,2,PA), (2,3,VI) ]

          This matches.
