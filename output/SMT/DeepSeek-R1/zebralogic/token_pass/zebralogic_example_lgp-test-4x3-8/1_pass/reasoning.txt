 We have 4 houses, each with a name, hair color, and music genre.
 We'll define three sets of variables: one for names, one for hair colors, and one for music genres, each for the 4 houses.

 3. Add constraints that each attribute (name, hair color, music genre) is a permutation of the possible values.
 4. Add the constraints from the clues.

 Note: Since the houses are in order (1 to 4), we can use the indices 0 to 3 for house 1 to 4.

 Let's break down:

 We have 4 houses: house1, house2, house3, house4.

 We'll create:
   Names: Eric, Arnold, Peter, Alice
   Hair colors: blonde, black, brown, red
   Music genres: pop, jazz, rock, classical

 We'll create arrays for each attribute for each house.

 Steps in code:
   from z3 import *

   s = Solver()

   # We represent each house by an index (0 to 3 for house1 to house4)
   houses = range(4)

   # Define the attributes and their possible values as strings.
   names = ['Eric', 'Arnold', 'Peter', 'Alice']
   hair_colors = ['blonde', 'black', 'brown', 'red']
   music_genres = ['pop', 'jazz', 'rock', 'classical']

   # We create three arrays of Z3 constants for the attributes.
   # Instead of using integers and then mapping, we can use EnumSort for each attribute, but for simplicity we use integers and then map to strings.
   # Alternatively, we can use IntSort and then use distinct and constraints for the range, but using EnumSort is more straightforward.

   # Let's create EnumSort for each attribute type.

   NameSort, (Eric, Arnold, Peter, Alice) = EnumSort('Name', ['Eric', 'Arnold', 'Peter', 'Alice'])
   HairSort, (blonde, black, brown, red) = EnumSort('Hair', ['blonde', 'black', 'brown', 'red'])
   MusicSort, (pop, jazz, rock, classical) = EnumSort('Music', ['pop', 'jazz', 'rock', 'classical'])

   # Now, for each house, we create a variable for name, hair, and music.
   name = [Const('name_%d' % i, NameSort) for i in houses]
   hair = [Const('hair_%d' % i, HairSort) for i in houses]
   music = [Const('music_%d' % i, MusicSort) for i in houses]

   # Each attribute must be distinct.
   s.add(Distinct(name))
   s.add(Distinct(hair))
   s.add(Distinct(music))

   # Now add the constraints from the clues.

   # 1. Eric is the person who has red hair.
   #    For the house where name is Eric, hair is red.
   for i in houses:
        s.add(Implies(name[i] == Eric, hair[i] == red))

   # 2. The person who loves classical music is directly left of the person who has blonde hair.
   #    classical in house i, then blonde in house i+1.
   for i in range(3):  # i from 0 to 2 (so that i+1 is 3 at max)
        s.add(Implies(music[i] == classical, hair[i+1] == blonde))

   # 3. The person who has brown hair is not in the first house.
   s.add(hair[0] != brown)

   # 4. The person who loves pop music is not in the third house.
   s.add(music[2] != pop)

   # 5. The person who loves classical music is in the first house.
   s.add(music[0] == classical)

   # 6. The person who loves jazz music is the person who has red hair.
   #    So for every house, if music is jazz then hair is red, and vice versa?
   #    Actually, it says they are the same person, so in the same house.
   for i in houses:
        s.add(Implies(music[i] == jazz, hair[i] == red))
        s.add(Implies(hair[i] == red, music[i] == jazz))

   # 7. The person who loves rock music is Arnold.
   for i in houses:
        s.add(Implies(music[i] == rock, name[i] == Arnold))

   # 8. Peter is somewhere to the right of the person who loves rock music.
   #    Let rock_music_house = i, then Peter must be in a house j>i.
   #    We can express: there exists i and j such that music[i]==rock and name[j]==Peter and j>i.
   #    Alternatively, we can say that the house of rock music is less than the house of Peter.
   rock_house = Int('rock_house')
   peter_house = Int('peter_house')
   s.add(rock_house >= 0, rock_house < 4)
   s.add(peter_house >= 0, peter_house < 4)
   for i in houses:
        s.add(Implies(music[i] == rock, rock_house == i))
        s.add(Implies(name[i] == Peter, peter_house == i))
   s.add(peter_house > rock_house)

   # Now, check and get the model.

   if s.check() == sat:
        m = s.model()
        # We will create a list for each house, then output in the required JSON format.
        result = []
        for i in houses:
            n = m.evaluate(name[i])
            h = m.evaluate(hair[i])
            m_genre = m.evaluate(music[i])
            # Convert the Z3 constants to strings
            n_str = str(n)
            h_str = str(h)
            m_str = str(m_genre)
            result.append([str(i+1), n_str, h_str, m_str])
        # Format the output as JSON
        output = {
            "solution": {
                "header": ["House", "Name", "HairColor", "MusicGenre"],
                "rows": result
            }
        }
        # Print the JSON
        import json
        print(json.dumps(output, indent=2))
   else:
        print("No solution found")
