We are given 5 houses, each with a unique name and a unique height.
 Names: Peter, Alice, Bob, Eric, Arnold
 Heights: very tall, average, tall, very short, short

 Clues:
 1. The person who is short is in the second house.
 2. Peter is directly left of Bob. (So Peter's house number = Bob's house number - 1)
 3. Eric is somewhere to the left of Peter. (Eric's house number < Peter's house number)
 4. The person who is very tall is directly left of Peter. (So very tall's house number = Peter's house number - 1)
 5. Alice is directly left of the person who has an average height. (Alice's house number = average height's house number - 1)
 6. The person who is short and the person who is very short are next to each other. (|short house - very short house| = 1)
 7. The person who has an average height is in the fifth house.

 We note from clue 7 that average height is in house 5.
 Then from clue 5, Alice is directly left of the average height person, so Alice must be in house 4.

 Also, from clue 1, short is in house 2.

 We have to assign the names and heights to houses 1 to 5.

 Steps:
 1. We'll create two arrays for names and heights, each of length 5 (index 0 to 4 for house 1 to 5).
 2. We'll use Z3 to set up the constraints.

 However, note that some clues are already giving fixed positions:
   - House 2: height = short
   - House 4: name = Alice
   - House 5: height = average

 Also, from clue 2: Peter is directly left of Bob -> Peter in house i, Bob in house i+1.
 From clue 4: very tall is directly left of Peter -> very tall in house j, Peter in house j+1.

 From clue 3: Eric is left of Peter -> Eric's house < Peter's house.

 From clue 6: short (house 2) and very short are adjacent -> very short must be in house 1 or house 3.

 Implementation:

   from z3 import *

   # Define the sorts
   Name = Datatype('Name')
   for n in ['Peter', 'Alice', 'Bob', 'Eric', 'Arnold']:
       Name.declare(n)
   Name = Name.create()

   Height = Datatype('Height')
   for h in ['very_tall', 'average', 'tall', 'very_short', 'short']:
       Height.declare(h)
   Height = Height.create()

   # Create arrays for house names and heights
   names = [Const('name_%d' % i, Name) for i in range(5)]
   heights = [Const('height_%d' % i, Height) for i in range(5)]

   # Create solver
   s = Solver()

   # Distinct constraints
   s.add(Distinct(names))
   s.add(Distinct(heights))

   # Fixed assignments from clues
   s.add(heights[1] == Height.short)   # house 2
   s.add(names[3] == Name.Alice)        # house 4
   s.add(heights[4] == Height.average)  # house 5

   # Now, define the house index variables for each person and each height we care about.
   peter_house = Int('peter_house')
   bob_house = Int('bob_house')
   eric_house = Int('eric_house')
   arnold_house = Int('arnold_house')

   very_tall_house = Int('very_tall_house')
   tall_house = Int('tall_house')
   very_short_house = Int('very_short_house')

   # We already know:
   short_house = 1   # (index 1)
   average_house = 4 # (index 4)
   alice_house = 3   # (index 3)

   # Now, for each of these index variables, we constraint them to be the index where the corresponding name or height appears.
   for i in range(5):
      s.add(If(names[i] == Name.Peter, peter_house == i, True))
      s.add(If(names[i] == Name.Bob, bob_house == i, True))
      s.add(If(names[i] == Name.Eric, eric_house == i, True))
      s.add(If(names[i] == Name.Arnold, arnold_house == i, True))

      s.add(If(heights[i] == Height.very_tall, very_tall_house == i, True))
      s.add(If(heights[i] == Height.tall, tall_house == i, True))
      s.add(If(heights[i] == Height.very_short, very_short_house == i, True))

   # Now add the constraints:

   # Clue 2: Peter is directly left of Bob -> peter_house + 1 == bob_house
   s.add(peter_house + 1 == bob_house)

   # Clue 3: Eric is left of Peter -> eric_house < peter_house
   s.add(eric_house < peter_house)

   # Clue 4: The person who is very tall is directly left of Peter -> very_tall_house + 1 == peter_house
   s.add(very_tall_house + 1 == peter_house)

   # Clue 5 is already used (Alice left of average, and average in 5, so Alice in 4)

   # Clue 6: The person who is short (house index 1) and very_short are adjacent -> |very_short_house - 1| == 1
   s.add(Or(very_short_house == 0, very_short_house == 2))

   # Clue 7 is already set.
