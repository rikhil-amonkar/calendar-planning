Let's break this down step by step before jumping into the code.

**Constraints recap:**
- Total days: 15
- Cities & required days:
  - Vienna: 4 days (must include day 1 and day 4 for conference)
  - Milan: 2 days
  - Rome: 3 days
  - Riga: 2 days
  - Lisbon: 3 days (must be between day 11 and day 13 inclusive)
  - Vilnius: 4 days
  - Oslo: 3 days (must be between day 13 and day 15 inclusive)

**Direct flights list** (interpreted as bidirectional except where "from X to Y" is specified — but here all seem bidirectional except one, but we'll treat as bidirectional for simplicity unless otherwise stated; the given "from Rome to Riga" likely means Rome→Riga exists, but we'll assume symmetry for planning unless impossible).

**Approach:**
We need to schedule 7 stays in 15 days, with fixed constraints on certain days for certain cities.  
We can treat this as a **constraint satisfaction problem** with a sequence of cities, each stay lasting a certain number of days, flights possible between consecutive cities.

We'll brute-force search over permutations of stays (each stay = city + duration) that match total days = 15, match required durations per city, match fixed day constraints, and have direct flights between consecutive cities.

**Fixed day constraints mean:**
- Day 1: Vienna
- Day 4: Vienna
- Days 11–13: Lisbon
- Days 13–15: Oslo

Wait — Days 13–15 Oslo and Days 11–13 Lisbon overlap on day 13. That means day 13 must be in both Lisbon and Oslo — impossible unless it's a travel day.  
But the rule says: if you fly from A to B on day X, you are in both A and B on day X. So day 13 could be a travel day Lisbon → Oslo, satisfying both constraints (day 13 counts for Lisbon and Oslo). That’s allowed.

Similarly, day 4 in Vienna means Vienna on day 4, but could be travel from/to Vienna on that day.

**We'll implement:**
1. Represent each stay as (city, start_day, end_day inclusive).
2. Enforce fixed days:  
   - Day 1 in Vienna → first stay must include day 1 and be Vienna.  
   - Day 4 in Vienna → some stay includes day 4 and is Vienna.  
   - Days 11–13 in Lisbon → some stay covers all days 11,12,13 and is Lisbon.  
   - Days 13–15 in Oslo → some stay covers all days 13,14,15 and is Oslo.  
   But day 13 appears in both Lisbon and Oslo stays → that’s only possible if Lisbon stay ends day 13 and Oslo starts day 13 (same day travel).
3. So Lisbon stay: end_day = 13, start_day = 11 (3 days: 11,12,13).  
   Oslo stay: start_day = 13, end_day = 15 (3 days: 13,14,15).  
   So day 13 is travel Lisbon→Oslo.
4. Vienna: must total 4 days, includes day 1 and day 4. Could be split into two stays? Possibly, but simpler to keep as one stay covering both day 1 and day 4.  
   Minimal start day = 1, maximal end day = something >4, but must fit other cities before/after.
5. We'll search over sequences of stays (order of cities) with given durations, flights allowed between consecutive.

Also Rome–Lisbon given.

**Durations:**
Vienna 4, Milan 2, Rome 3, Riga 2, Lisbon 3, Vilnius 4, Oslo 3. Sum = 21 days.  
But total days = 15.  
Why? Because travel days count for both cities, so overlapping days reduce total.  
If we have 7 stays, there are 6 travel days. Each travel day is counted in both stays, so total "stay days" sum = 15 + 6 = 21. Yes, matches.

So each travel day is an overlap between two consecutive stays.

**We need to assign:**
- 7 stays with given lengths (4,2,3,2,3,4,3) in some order matching cities.
- Consecutive stays share one day (travel day).
- Fixed constraints on certain days for certain cities.

We'll brute-force search over permutations of cities with these durations, check flight connections, then assign days to see if fixed day constraints fit.

Here’s the Python program implementing this search:

```python
import itertools
import json

def flight_possible(city1, city2):
    flights = {
        ("Riga", "Oslo"),
        ("Rome", "Oslo"),
        ("Vienna", "Milan"),
        ("Vienna", "Vilnius"),
        ("Vienna", "Lisbon"),
        ("Riga", "Milan"),
        ("Lisbon", "Oslo"),
        ("Rome", "Riga"),
        ("Vienna", "Riga"),
        ("Vienna", "Rome"),
        ("Milan", "Oslo"),
        ("Vienna", "Oslo"),
        ("Vilnius", "Oslo"),
        ("Riga", "Vilnius"),
        ("Vilnius", "Milan"),
        ("Riga", "Lisbon"),
        ("Milan", "Lisbon"),
        ("Rome", "Lisbon")
    }
    return (city1, city2) in flights or (city2, city1) in flights

def check_itinerary(city_order, durations):
    # city_order: list of 7 cities, durations: list of 7 ints
    # Check flights between consecutive
    for i in range(len(city_order) - 1):
        if not flight_possible(city_order[i], city_order[i+1]):
            return False
    
    # Assign days
    # Start day 1
    day = 1
    stays = []
    for i in range(len(city_order)):
        length = durations[i]
        stays.append((city_order[i], day, day + length - 1))
        day += length - 1  # next stay starts on last day of current stay (overlap travel day)
    
    # Check total days = 15
    if stays[-1][2] != 15:
        return False
    
    # Check fixed constraints
    day_in_city = {}
    for city, start, end in stays:
        for d in range(start, end + 1):
            day_in_city[d] = city
    
    # Day 1 in Vienna
    if day_in_city.get(1) != "Vienna":
        return False
    # Day 4 in Vienna
    if day_in_city.get(4) != "Vienna":
        return False
    # Days 11-13 in Lisbon
    for d in range(11, 14):
        if day_in_city.get(d) != "Lisbon":
            return False
    # Days 13-15 in Oslo
    for d in range(13, 16):
        if day_in_city.get(d) != "Oslo":
            return False
    
    # Check each city total days = required
    city_days = {}
    for city, start, end in stays:
        city_days[city] = city_days.get(city, 0) + (end - start + 1)
    required = {"Vienna": 4, "Milan": 2, "Rome": 3, "Riga": 2, "Lisbon": 3, "Vilnius": 4, "Oslo": 3}
    for city, req in required.items():
        if city_days.get(city, 0) != req:
            return False
    
    return stays

def main():
    cities = ["Vienna", "Milan", "Rome", "Riga", "Lisbon", "Vilnius", "Oslo"]
    durations = [4, 2, 3, 2, 3, 4, 3]
    
    # We need to permute cities but keep durations fixed as above order? No, durations tied to cities.
    # Actually, we need to assign each city one duration from the list, but each city has fixed required days.
    # So we just permute cities and check if durations match required.
    # Required days per city:
    req_days = {"Vienna": 4, "Milan": 2, "Rome": 3, "Riga": 2, "Lisbon": 3, "Vilnius": 4, "Oslo": 3}
    
    # We'll generate permutations of cities
    for perm in itertools.permutations(cities):
        # durations for this permutation
        dur = [req_days[city] for city in perm]
        stays = check_itinerary(perm, dur)
        if stays:
            # Convert to output format
            itinerary = []
            for city, start, end in stays:
                if start == end:
                    day_range = f"Day {start}"
                else:
                    day_range = f"Day {start}-{end}"
                itinerary.append({"day_range": day_range, "place": city})
            
            result = {"itinerary": itinerary}
            print(json.dumps(result, indent=2))
            return
    
    print(json.dumps({"itinerary": []}))

if __name__ == "__main__":
    main()
```
