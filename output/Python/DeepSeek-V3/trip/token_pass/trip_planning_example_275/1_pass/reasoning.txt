Let's break down the problem first.

**Given constraints:**
- Total days: 14
- Split: 5 days
- Vilnius: 4 days
- Santorini: 2 days
- Madrid: 6 days
- Day 13–14: Must be in Santorini (conference)
- Direct flights exist only between:
  - Vilnius ↔ Split
  - Split ↔ Madrid
  - Madrid ↔ Santorini

**Observations:**
- Total days required = 5 + 4 + 2 + 6 = 17 days, but we only have 14 days.  
  This means some days are counted twice because travel days count for both cities.
- If you fly from A to B on day X, day X counts for both A and B in the totals.
- We must end in Santorini on days 13–14.

**Graph of connections:**
Vilnius — Split — Madrid — Santorini  
It’s a linear path:  
Vilnius ↔ Split ↔ Madrid ↔ Santorini

**Key:**
- Santorini is at one end (connected only to Madrid).
- Vilnius is at the other end (connected only to Split).
- So any itinerary must go through intermediate cities in sequence.

**Travel constraints:**
- To go from Vilnius to Santorini, you must pass Split and Madrid.
- To go from Santorini to Vilnius, you must pass Madrid and Split.

**We must satisfy:**
1. Santorini total = 2 days, with days 13–14 fixed there.
2. Madrid total = 6 days.
3. Split total = 5 days.
4. Vilnius total = 4 days.

Let’s denote travel days (where a day is spent in two cities):
- Each travel between adjacent cities uses 1 day that counts for both cities.
- If we have T travel segments, that means T days are double-counted.
- Total “city-days” counted = 5 + 4 + 2 + 6 = 17.
- Actual days available = 14.
- So overcount = 17 − 14 = 3 days.
- Each travel segment reduces total counted days by 1 (because it merges two city-days into one calendar day).
- So we need exactly 3 travel segments to reduce 17 to 14.

**Possible itineraries:**
We have 4 cities in a line:  
V – S – M – T  (Vilnius, Split, Madrid, Santorini)

We must start somewhere and end in Santorini on day 14.
We must have exactly 3 travel segments (edges) used, because 3 double-count days.

With 4 cities, minimal edges to visit all cities = 3 edges (a path through all 4 cities).  
That means we visit each city exactly once in sequence, with no backtracking.  
That uses exactly 3 travel days, perfect.

So the trip is: Start in one end city, go through each city in sequence to the other end.

But Santorini must be last (days 13–14 there).  
So the sequence must end with Santorini.  
Thus the only possible sequence is:  
Vilnius → Split → Madrid → Santorini  
or  
Split → Vilnius → Split → Madrid → Santorini? Wait, that revisits Split, which would add extra travel days beyond 3, so not allowed (we need exactly 3 travel segments).

So simple path visiting all 4 cities in some order, ending in Santorini.

Two possibilities:
1. Vilnius → Split → Madrid → Santorini
2. Split → Vilnius → Split → Madrid → Santorini → (but this repeats Split, so edges: Split–Vilnius, Vilnius–Split, Split–Madrid, Madrid–Santorini = 4 edges = 4 travel days → overkill, reduces 17 to 13, too much).

So only simple path without revisits.

If Santorini is last, Madrid must be before it, Split before Madrid, Vilnius before Split.  
So only possible route:  
Vilnius → Split → Madrid → Santorini.

Now assign days:

Let’s denote:
- Day X: travel from Vilnius to Split
- Day Y: travel from Split to Madrid
- Day Z: travel from Madrid to Santorini

Each travel day counts for both cities.

We need:
Vilnius total 4 days.  
If we start in Vilnius on day 1, stay until day X (inclusive), then Vilnius days = X.  
So X = 4.

Split total 5 days.  
Split days = days from X to Y inclusive.  
So Y − X + 1 = 5 → Y = X + 4 = 8.

Madrid total 6 days.  
Madrid days = days from Y to Z inclusive.  
So Z − Y + 1 = 6 → Z = Y + 5 = 13.

Santorini total 2 days.  
Santorini days = days from Z to 14 inclusive.  
So 14 − Z + 1 = 2 → Z = 13. Yes, consistent.

Check:
- Vilnius: days 1–4 = 4 days.
- Split: days 4–8 = 5 days (day 4 is both Vilnius and Split, counts for Split).
- Madrid: days 8–13 = 6 days (day 8 is both Split and Madrid, counts for Madrid).
- Santorini: days 13–14 = 2 days (day 13 is both Madrid and Santorini, counts for Santorini).

Total calendar days: 14. Perfect.
