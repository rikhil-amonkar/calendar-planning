4. Output day and time in `HH:MM:HH:MM` format.

**Step 3 — Data parsing**  
We’ll parse Nicole’s and Daniel’s schedules into a list of busy intervals per day.

**Step 4 — Algorithm**  
Loop through days in order (Mon–Fri).  
For each day, merge both people’s busy intervals, sort, then find gaps ≥ 60 minutes between 9:00 and 17:00.  
Pick the first such gap.
