    """Convert time string like '9:00' to datetime object"""

    """Convert datetime object to string like '9:00'"""

This program systematically explores different meeting orders while respecting:
1. Travel times between locations
2. Each person's availability window
3. Minimum meeting duration requirements
4. Starting from Chinatown at 9:00 AM

The algorithm tries to maximize the number of meetings first, then maximizes total meeting duration. If no schedule meets all minimum duration requirements, it tries with relaxed durations (half of original, minimum 15 minutes).
