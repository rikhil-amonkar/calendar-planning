Goal: Maximize number of friends met, respecting:
1. Travel time between locations
2. Their availability windows
3. Our start time and sequential schedule

**Step 4 — Approach**  
We can brute-force search over permutations of meetable friends (excluding Kevin, possibly excluding Barbara if her 120-minute requirement makes others impossible).  
But since the number of friends is small, we can try a heuristic:  
We start at Presidio at 9:00, we can meet Helen first (North Beach 11:00–12:15, need 45 min).  
We must arrive by 11:00, leave by 12:15. Travel from Presidio to North Beach is 18 minutes, so we can leave Presidio at 10:42, arrive 11:00, meet until 11:45, leave.

Then from North Beach, we can go to another friend available later in the day.

We must check feasibility sequentially:  
For each candidate friend after current time + travel, they must have enough time left in their window for the minimum duration.
