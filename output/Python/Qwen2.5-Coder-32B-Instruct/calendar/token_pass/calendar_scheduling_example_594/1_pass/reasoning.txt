To solve this scheduling problem, we need to identify overlapping free time slots between all participants that satisfy the meeting duration constraint. Here's a step-by-step approach to achieve this:

1. **Parse the Input Data**: We need to store the busy times of each participant. This can be done using lists of tuples, where each tuple represents a start and end time of a busy period.

2. **Determine Available Time Slots**: For each participant, calculate the available time slots by identifying gaps between their busy periods within the working hours (9:00 to 17:00).

3. **Find Common Free Time Slots**: Compare the available time slots of all participants to find common slots that fit the meeting duration.

4. **Select the Earliest Suitable Slot**: Once we have identified common free slots, select the earliest one as per the requirement.

5. **Output the Result**: Format the output to display the earliest common free slot along with the day of the week.
