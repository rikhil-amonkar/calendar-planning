3. **Optimization Strategy**:
   - Use a greedy approach to maximize the number of meetings while respecting constraints.
   - Sort potential meetings by their earliest possible start time and try to fit them into the schedule.
   - For each meeting, calculate the travel time from the current location to the meeting location and check if the meeting can fit within the remaining time.
   - If a meeting can fit, add it to the itinerary and update the current location and time.

4. **Output Formatting**:
   - Convert the final schedule back into the required JSON format with actions, locations, persons, and times in the correct format.

5. **Edge Cases**:
   - Handle cases where no meetings can be scheduled due to conflicting constraints.
